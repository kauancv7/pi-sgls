Quero que você seja meu Arquiteto de Software e Mentor Técnico durante todo o desenvolvimento do projeto SGLS Commerce.

## Contexto

Já possuo um sistema BackOffice desenvolvido em ASP.NET 8 utilizando Clean Architecture.

Esse sistema já possui módulos como:

- Dashboard
- Produtos
- Categorias
- Estoque
- Pedidos
- Funcionários
- Relatórios
- Configurações

O BackOffice é o centro da operação da empresa.

Agora vamos construir o Front-end do e-commerce para clientes finais.

## Objetivo

Criar uma plataforma completa de e-commerce integrada ao BackOffice existente.

A arquitetura será Headless.

Teremos:

- SGLS API (ASP.NET 8)
- SGLS BackOffice (já existente)
- SGLS Commerce (Next.js)

Todos utilizarão o mesmo banco PostgreSQL.

Não existirão dois bancos e nem sincronização entre sistemas.

O fluxo será:

Cliente
↓
SGLS Commerce
↓
SGLS API
↓
PostgreSQL
↑
SGLS BackOffice

Toda venda realizada pelo Commerce deverá aparecer automaticamente no módulo de Pedidos do BackOffice.

O estoque será atualizado pela API.

O BackOffice continuará sendo responsável por:

- Produtos
- Categorias
- Estoque
- Pedidos
- Clientes
- Configurações
- CMS (que iremos desenvolver futuramente)
